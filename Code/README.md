
# Code

This directory contains the source code and supporting data files developed for the IR Sensor-Based Risk Prediction System.

The project integrates Python for sensor data processing and visualization with VHDL for simulated inference.

## Subdirectories

- **Python:** Scripts for sensor data acquisition, processing, file-based communication, and graphical visualization.
- **VHDL:** VHDL source files implementing the inference logic and simulation testbench.
- **Data:** Sample input and output text files used for data exchange between Python and VHDL simulation.

## Technologies Used

- Python
- VHDL
- Arduino Serial Communication
- Xilinx Vivado
