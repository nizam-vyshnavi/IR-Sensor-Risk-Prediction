
# Python Implementation

This folder contains the Python scripts used in the IR Sensor-Based Risk Prediction System. Python acts as the interface between the Arduino sensor data, VHDL simulation, and graphical visualization.

## Files

### 1. sensor_simulator.py

This script receives sensor readings from the Arduino through serial communication. It processes the incoming sensor values, maps them into risk-related values, and writes the processed data into `input.txt` for the VHDL simulation.

**Functions:**
- Establishes serial communication with Arduino.
- Reads sensor values.
- Processes and validates incoming data.
- Maps sensor readings into risk values.
- Writes the processed values to `input.txt`.

### 2. live_plot.py

This script reads the prediction values generated by the VHDL simulation from `output.txt` and displays them graphically using Matplotlib.

**Functions:**
- Reads prediction values from the output file.
- Updates the graph periodically.
- Displays the prediction results visually.
- Helps monitor changes in risk analysis.

### 3. test_bnn.py

This file contains an initial Cocotb-based testing setup intended for testing the VHDL design through Python.

The script represents an experimental testing approach and is currently an incomplete testbench template.

## Data Flow

```text
Arduino Sensor Data
        |
        v
sensor_simulator.py
        |
        v
input.txt
        |
        v
VHDL Simulation
        |
        v
output.txt
        |
        v
live_plot.py
        |
        v
Graphical Visualization
```

## Libraries Used

- `pyserial` – Serial communication with Arduino.
- `matplotlib` – Graphical visualization of prediction results.
- `time` – Timing and periodic execution.
- `cocotb` – Experimental VHDL testing framework.

## Note

The Python scripts are part of a simulation-based hardware-software integration project. Python handles sensor data acquisition, processing, file communication, and visualization, while the inference logic is implemented and executed in VHDL simulation.
