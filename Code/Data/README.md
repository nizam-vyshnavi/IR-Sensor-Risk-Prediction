# Sample Data

This directory contains sample input and output files used to demonstrate the data exchange between the Python scripts and the VHDL simulation.

## Files

- **sample_input.txt:** Contains sample IR sensor values provided as input to the VHDL simulation.
- **sample_output.txt:** Contains example prediction output values generated by the simulation.

These files demonstrate the file-based communication workflow used in the project.

## Data Format

- Input data consists of IR sensor readings.
- Output data contains prediction values generated by the VHDL simulation.

The files are provided as sample data for demonstration purposes.
